# 최종본 계획표

사장님이 2026-11-20에 "모두 그렇게 해 주세요"라고 하신 것들을 만드는 순서와 진행 상황이에요.
사용 한도에 걸리면 예약된 이어하기가 이 파일을 보고 남은 일을 계속해요.
(`[x]` 끝남 · `[~]` 하는 중 · `[ ]` 아직)

## 사장님이 정하신 것
- 앱 시작일은 아직 미정(12월 또는 더 빨리). 정하기 전에는 '시작 전'.
- 사무실은 왕십리·창동 두 곳: `사무실(왕)`, `사무실(창)`. 예전 자료의 `사무실(영)`은 `사무실(왕)`.
- 월차는 넉넉하게: 입사한 달도 입사일 뒤로 결근이 없으면 만근.
- 지난 결근은 14일 안이면 월차·대체휴무로도 바꿔 달라고 요청할 수 있음(승인은 사장님).
- 점장은 자기 지점 신입 대기와 직원 이름·휴대폰만. 승인·주민번호·계좌는 사장님만.
- 폰은 사장님 승인으로 2대까지. 지원 간 날 지각은 지원 간 매장 시간 기준.
- 신입 쉬는 요일은 승인할 때 고름(나중에 정하기도 가능). 입사 등록에는 입사 코드(숫자 4자리).
- 지원 근무는 누가 어디로 몇 번 갔는지 잘 보여야 함.
- 급여·세금 계산, 매출·재고는 넣지 않음.
