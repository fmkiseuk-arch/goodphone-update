# 다른 앱·실무에서 가져올 것 조사 메모 (2026-11-20)

사장님이 "다른 앱이나 실무에서 추가할 게 더 있을 것"이라고 하셔서 조사한 내용이에요.
**근거 수준에 주의하세요.** 이 작업 환경에서는 해당 사이트 본문을 열 수 없어서, 모든 항목은 검색 결과에 나온 요약 문장만 보고 정리했어요. 원문을 읽어 확인한 것은 없고, `기억(확인 못 함)`이라고 적힌 항목은 근거를 찾지 못한 일반 관행이에요.

## 매장 인사·근태 실무에서 생기는 상황(변수)

조사 범위: 웹 검색 13번을 했고, 검색 결과 요약까지는 확인했어요. 하지만 페이지 본문 읽기는 10번 시도해 모두 실패했어요(www.shoplworks.com, shiftee.io, zuzu.network가 이 세션의 네트워크 허용 목록에 없어서 열리지 않았어요. 본문 확인이 필요하면 세션 네트워크 설정에서 이 주소들을 허용해야 해요). 그래서 모든 항목의 근거는 '검색 결과 요약' 수준이고, 법 조문이나 원문을 직접 읽고 확인한 것은 없어요. 근거를 못 찾은 항목(오픈·마감 담당과 열쇠, 성수기 휴무 제한, 폰 분실 때 대안, 비상 연락망, 점장 대행, 생일·근속)은 source에 '기억(확인 못 함)'으로 적었어요. 휴대폰 매장만 다룬 자료는 찾지 못했고, 일반 소매·사무직 근태 자료를 매장 사정에 맞춰 옮겼어요. 겸직, 직원 여러 매장 동시 소속, 가짜 GPS 탐지 방법은 쓸 만한 자료가 나오지 않았어요. 병가·경조·건강검진·휴게 시간처럼 법과 닿는 내용은 회사 규칙으로 정할 부분이 많아서, 실제로 정할 때는 노무사나 고용노동부(1350) 확인이 필요해요. 2026년 12월 휴게 시간 개정 보도는 검색 요약에서만 봤고 확정 내용은 확인하지 못했어요.

- **[매장 밖 근무 · 쓸모 높음 · 우리 앱: 없음] 외근·교육·회의·출장 날 출근 처리**
  - 내용: 매장 밖에서 일하는 날은 GPS 출근이 안 돼요. 근태 서비스들은 '외근·출장'을 따로 등록해 두면 정해진 근무 시간만큼 일한 것으로 처리하는 방식을 써요. 공공기관 근태 세칙도 외근을 외출·조퇴와 다른 종류로 나눠요.
  - 넣는다면: 요청 종류에 '외근·교육·회의'를 추가해요(날짜, 시간, 장소, 사유). 승인되면 그날은 GPS 없이 출근·퇴근 버튼이 눌리고 기록에 '외근' 표시가 붙어요. 미출근 알림과 결근 의심에서도 빠지게 해요.
  - 근거: shiftee.io/ko/blog/article/attendanceManagement, 부천도시공사 근태관리 시행세칙(best.or.kr) - 검색 요약으로 확인, 본문은 못 열어 봄
- **[매장 밖 근무 · 쓸모 높음 · 우리 앱: 일부 있음] 다른 매장 지원 근무(파견) 기록**
  - 내용: 다점포용 근태 앱은 '등록된 근무지 어디서나 출퇴근 체크'를 기본으로 해요. 소속 매장이 아닌 곳에서 찍으면 어느 매장에서 찍었는지 남기는 방식이에요. 직원이 지원 간 날 소속 매장이 사람 부족으로 보이지 않게 하는 것도 중요해요.
  - 넣는다면: '다른 매장' 출근은 이미 있으니, 지원을 미리 잡는 칸을 더해요. 점장이 '며칠, 누구를, 어느 매장으로'를 넣으면 오늘 현황에서 그 사람이 지원 간 매장 쪽에 보이고 휴무표에 '지원' 표시가 남아요. 월별 합계에 지원 근무 일수도 한 줄 넣어요.
  - 근거: 핀앳(Pinat) 앱 소개, 샵솔 앱 소개(앱스토어) - 검색 요약으로 확인
- **[근무 중 예외 · 쓸모 높음 · 우리 앱: 없음] 외출(잠깐 나갔다 오기) 기록**
  - 내용: 근태 규정 예시들은 외출·조퇴를 미리 신청하고 승인받는 것을 원칙으로 하고, 급할 때만 나중에 처리하도록 해요. 사유(병원, 은행 등)를 꼭 적게 하는 곳이 많아요. 법에는 외출 규정이 따로 없어서 회사가 기준을 정해야 해요.
  - 넣는다면: 직원 화면에 '외출 시작 / 복귀' 버튼을 두고 사유를 한 줄 적게 해요. 기록 탭에 외출 시간이 남고 점장에게 텔레그램이 가요. 승인까지 받게 할지, 알리기만 할지는 설정으로 고르게 해요.
  - 근거: bizforms.co.kr/guide365/298, 부천도시공사 근태관리 시행세칙, shiftee.io 지각·조퇴 글 - 검색 요약으로 확인
- **[근무 중 예외 · 쓸모 높음 · 우리 앱: 일부 있음] 조퇴와 반차를 헷갈리지 않게 구분**
  - 내용: 조퇴는 휴가가 깎이지 않는 대신 그 시간이 근무로 안 잡히고, 반차는 휴가를 0.5개 쓰는 거예요. 담당자가 반차를 조퇴로 잘못 넣어 직원이 손해 본 사례가 소개돼 있어요. 조퇴가 쌓였다고 자동으로 휴가를 깎는 것은 문제 될 수 있다는 설명도 있어요.
  - 넣는다면: 일찍 퇴근 버튼을 누를 때 '반차로 쓸까요, 조퇴로 남길까요?'를 묻고, 반차를 고르면 바로 반차 요청이 만들어지게 해요. 조퇴에는 사유 칸을 꼭 채우게 해요.
  - 근거: shiftee.io/ko/blog/article/can-leave-be-deducted-for-lateness-early-leave-guide, shoplworks.com 조퇴·반차 차이 글 - 검색 요약으로 확인
- **[휴가 종류 · 쓸모 중간 · 우리 앱: 없음] 반반차(2시간 단위 휴가)**
  - 내용: 근태 서비스들은 휴가를 종일·반차·반반차 단위로 나눠 관리해요. 병원이나 관공서처럼 2시간이면 되는 일에 반차를 통째로 쓰지 않아도 돼요.
  - 넣는다면: 월차를 한 달에 1개씩 주는 구조라 0.25 단위까지 쪼갤지는 사장님이 정해야 해요. 넣는다면 요청 종류에 '반반차(오전/오후 2시간)'를 추가하고 월차 잔여를 0.25씩 줄이면 돼요. 안 쓸 거면 설정에서 꺼 두면 돼요.
  - 근거: shiftee.io 근태관리 글, bizforms.co.kr 근태 규정 안내 - 검색 요약으로 확인
- **[휴가 종류 · 쓸모 높음 · 우리 앱: 없음] 예비군·민방위 공가**
  - 내용: 예비군법·민방위기본법은 훈련 받는 날을 쉬는 날로 치거나 불리하게 대하지 못하게 해요. 그래서 개인 휴가를 쓰게 하지 않고 '공가'로 처리하는 게 원칙이라고 안내돼요. 쉬는 날에 잡힌 훈련은 따로 처리할 게 없어요.
  - 넣는다면: 요청 종류에 '공가(예비군·민방위)'를 추가하고 통지서 사진을 붙일 수 있게 해요. 승인되면 휴무표에 '공가'로 표시되고 만근 계산에서 결근으로 세지 않게 해요. 젊은 남자 직원이 많은 매장이라 자주 쓰일 거예요.
  - 근거: easylaw.go.kr(예비군 및 민방위), shiftee.io 예비군 글, shoplworks.com 예비군 글 - 검색 요약으로 확인
- **[휴가 종류 · 쓸모 높음 · 우리 앱: 없음] 경조사 휴가(결혼·상)**
  - 내용: 경조사 휴가는 법으로 정해진 게 아니라 회사가 정하는 휴가예요. 참고 기준으로 본인 결혼 5일, 자녀 결혼 1일, 배우자·부모 상 5일, 조부모·형제자매 상 3일이 많이 쓰여요. 쉬는 날을 일수에 넣을지 미리 정해 두지 않으면 다툼이 생겨요.
  - 넣는다면: 요청 종류에 '경조'를 넣고 사유(결혼/상/기타)와 기간을 고르게 해요. 설정 시트에 사유별 기본 일수 표를 두면 사장님이 바꿀 수 있어요. 상은 급하니 '먼저 쉬고 나중에 승인'이 되도록 당일 신청을 허용해요.
  - 근거: law.go.kr 경조사 휴가 기준 별표, mpm.go.kr(인사혁신처), shiftee.io 경조휴가 글 - 검색 요약으로 확인
- **[휴가 종류 · 쓸모 높음 · 우리 앱: 일부 있음] 병가와 진단서**
  - 내용: 병가도 법에 정해진 휴가가 아니라 회사 규칙으로 운영해요. 1~3일 짧은 병가는 진단서 없이, 그보다 길면 진단서를 받는 회사가 많다고 해요. 아파서 못 나올 때는 빨리 알리고 기록을 남기는 게 중요하다고 안내돼요.
  - 넣는다면: 지금은 '무급'으로만 넣을 수 있으니 요청 종류에 '병가'를 따로 두고 진단서·처방전 사진을 붙이게 해요(사진은 구글 드라이브 폴더에 저장). 병가가 만근을 깨는지 여부는 설정에서 사장님이 고르게 해요.

  - 넣는다면: 따로 기능을 만들기보다 '공가' 요청의 사유 목록에 '건강검진'을 넣어 두면 충분해요. 인사 탭에 '검진 받은 날짜' 칸 하나를 두면 누가 안 받았는지 볼 수 있어요.

  - 내용: 폭설·폭우·태풍은 직원이 어쩔 수 없는 사유로 보는 게 보통이고, 늦는다는 사실을 바로 알리는 게 중요하다고 해요. 그런데 실제로는 이런 날도 휴가에서 깎는 회사가 있어서 기준을 미리 정해 두라고 권해요.

- **[출퇴근 예외 · 쓸모 높음 · 우리 앱: 일부 있음] 폰 분실·고장·배터리 방전일 때 출근**

## 다른 근태·인사 앱에 있는 기능

조사 범위: 검색은 15번 했어요. 페이지를 직접 여는 것은 6번 시도했지만 이 작업 환경의 네트워크 설정에서 shiftee.io, www.shoplworks.com, help.worksmobile.com, apps.apple.com이 모두 막혀 있어서 한 번도 못 열었어요. 그래서 모든 항목은 검색 결과에 나온 요약 문장만 보고 쓴 것이고, 원문을 읽어 확인한 것은 없어요. 원문 확인이 필요하면 이 네 주소를 세션 네트워크 설정에서 허용해야 해요.

확인된 범위: 시프티(출퇴근 인증, 퇴근 누락 처리, 알림, 결재 단계, 전자계약), 샤플(근태 이상 자동 알림, 근태 마감, 휴가 종류·당겨쓰기, 권한, 엑셀 리포트, 공지·할 일·보고서, QR·얼굴 인증), 뉴플로이(옛 알밤, 비콘·와이파이 인증, 관리자 지표, 수정 요청), 플렉스(연차 촉진, 승인·참조 결재선), 네이버웍스(내 업무 화면, 업무 봇, 연차 이관), 알바버니(일정 맞바꾸기).

확인 못 한 것: 카카오워크 근태 기능, 캡스워크·세콤 자체 근태 앱, 요금제 표, 도입 사례, 결재 위임(대신 승인), 시프티의 대타·근무 교환, 사진 인증, 보건증 만료 알림. 이 가운데 결재 위임과 퇴사 체크 목록은 서비스에서 본 것이 아니라 우리 쪽 제안으로 적었고 항목 안에 그렇게 표시했어요.

## 구글 Apps Script·폰 브라우저 쪽 변수 (개발자 메모, 실제 기기 확인 필요)

테스트는 모두 가짜 시트와 PC 크롬으로 했어요. 아래는 실제 환경에서 달라질 수 있는 것들이에요.

- **아이폰 사파리의 저장 공간**: Apps Script 웹 앱 화면은 구글 주소 안의 다른 주소(googleusercontent.com) 틀 안에서 열려요. 사파리는 이런 틀 안의 저장 공간(localStorage)을 따로 떼어 두고, 사파리가 완전히 꺼지면 지우는 것으로 알려져 있어요. 그러면 "이 폰" 번호와 기억해 둔 이름·비밀번호가 사라져서 **등록된 폰이 아니에요**가 다시 뜰 수 있어요. 실제 아이폰에서 꼭 확인해야 해요(출근 찍기 → 사파리를 완전히 껐다 켜기 → 다시 열기). 문제가 있으면 직원마다 "내 전용 주소"(주소에 열쇠가 든 링크)를 쓰는 방식으로 바꿔야 해요.
- **일주일 넘게 안 열면**: 사파리는 7일 동안 쓰지 않은 사이트의 저장 공간을 지워요. 긴 휴가 뒤 "새 폰"으로 잡힐 수 있어요.
- **하루 자동 실행 한도**: 무료 구글 계정은 자동 실행(트리거)이 하루에 쓸 수 있는 시간이 정해져 있어요(약 90분). 10분마다 도는 작업 한 번이 30초를 넘기 시작하면 한도에 가까워져요. 실행 시간을 기록해 두고, 밤에는 쉬게 하는 게 안전해요.
- **동시에 몰릴 때**: 한 번에 실행할 수 있는 수에 한도가 있어요(약 30개). 11시에 30명이 같이 누르면 닿을 수 있어서, 지금처럼 "누른 순간 기록 + 자동 다시 보내기"를 유지해야 해요.
- **주소가 공개예요**: 웹 앱 주소만 알면 누구나 이름 목록을 보고 입사 등록을 보낼 수 있어요. 승인 대기 20건 제한은 있지만, 하루 건수 제한과 "주소가 새면 새 배포로 바꾸기" 안내가 필요해요.
