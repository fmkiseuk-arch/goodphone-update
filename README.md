# 굳폰 통합문의 자동 업데이트

이 저장소의 **Releases**에 새 버전 설치 파일을 올리면, 매장·운영자 PC의 굳폰 통합문의 프로그램이 알아서 내려받아
영업시간이 아니고 아무도 PC를 안 쓸 때 설치합니다.

- 릴리스마다 올리는 파일 3개: `GoodphoneInbox-Setup-버전.exe`, `GoodphoneInbox-Setup-버전.exe.blockmap`, `latest.yml`
- 시트 [설정] 탭 '업데이트주소': `https://github.com/fmkiseuk-arch/goodphone-update/releases/latest/download`
- 설치 파일에는 연결 코드·시트 주소 같은 매장 정보가 들어 있지 않습니다.
